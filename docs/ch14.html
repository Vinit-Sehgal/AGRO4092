11.1 What we will explore

In the previous chapter, we fitted one model and obtained one set of optimized parameters. We will now ask:

  • Would the parameters change if we fitted a different subset of the observations?
  • How well does each model predict observations that were not used for fitting?
  • Where are the spatial parameter estimates stable, and where are they uncertain?

We will move through the ideas in a simple order:

one train/test split → k-fold cross-validation → repeated cross-validation → ensembles → parameter and prediction ranges → spatial uncertainty maps

The key change in perspective

The previous chapter asked, “What is the best fitted model?” This chapter asks, “How much does the fitted answer change?”

11.2.3 Reuse the physical model and fitting functions

The chapter is self-contained, so we repeat compact versions of the functions from the previous chapter. The revised optimization bounds remain unchanged.

piecewise_EF <- function(SM, theta_d, theta_w, EF_max) {
  ifelse(
    SM <= theta_d,
    0,
    ifelse(
      SM >= theta_w,
      EF_max,
      EF_max * (SM - theta_d) / (theta_w - theta_d)
    )
  )
}

model_error <- function(parameters, SM, EF) {
  predicted <- piecewise_EF(
    SM,
    parameters[1],
    parameters[2],
    parameters[3]
  )

  mean((EF - predicted)^2, na.rm = TRUE)
}
fit_NLS <- function(SM, EF) {
  keep <- is.finite(SM) & is.finite(EF)
  SM <- SM[keep]
  EF <- EF[keep]

  empty_result <- c(
    theta_d = NA_real_,
    theta_w = NA_real_,
    EF_max = NA_real_
  )

  if (length(SM) < 10 || length(unique(SM)) < 4) {
    return(empty_result)
  }

  lower <- c(
    theta_d = 0.02,
    theta_w = unname(quantile(SM, 0.35)),
    EF_max = 0.20
  )

  upper <- c(
    theta_d = unname(quantile(SM, 0.30)),
    theta_w = unname(quantile(SM, 0.98)),
    EF_max = 1.00
  )

  if (any(!is.finite(c(lower, upper))) || any(lower >= upper)) {
    return(empty_result)
  }

  model_data <- data.frame(SM = SM, EF = EF)

  search_grid <- expand.grid(
    theta_d = seq(lower["theta_d"], upper["theta_d"], length.out = 6),
    theta_w = seq(lower["theta_w"], upper["theta_w"], length.out = 6),
    EF_max = seq(lower["EF_max"], upper["EF_max"], length.out = 6)
  )

  start_fit <- nls2(
    EF ~ piecewise_EF(SM, theta_d, theta_w, EF_max),
    data = model_data,
    start = search_grid,
    algorithm = "brute-force"
  )

  fit <- nls(
    EF ~ piecewise_EF(SM, theta_d, theta_w, EF_max),
    data = model_data,
    start = as.list(coef(start_fit)),
    algorithm = "port",
    lower = lower,
    upper = upper,
    control = nls.control(maxiter = 200, warnOnly = TRUE)
  )

  parameters <- coef(fit)[c("theta_d", "theta_w", "EF_max")]
  setNames(as.numeric(parameters), names(empty_result))
}
fit_PSO <- function(SM, EF) {
  keep <- is.finite(SM) & is.finite(EF)
  SM <- SM[keep]
  EF <- EF[keep]

  empty_result <- c(
    theta_d = NA_real_,
    theta_w = NA_real_,
    EF_max = NA_real_
  )

  if (length(SM) < 10 || length(unique(SM)) < 4) {
    return(empty_result)
  }

  lower <- c(
    theta_d = 0.02,
    theta_w = unname(quantile(SM, 0.35)),
    EF_max = 0.20
  )

  upper <- c(
    theta_d = unname(quantile(SM, 0.30)),
    theta_w = unname(quantile(SM, 0.98)),
    EF_max = 1.00
  )

  if (any(!is.finite(c(lower, upper))) || any(lower >= upper)) {
    return(empty_result)
  }

  fit <- psoptim(
    par = (lower + upper) / 2,
    fn = model_error,
    SM = SM,
    EF = EF,
    lower = lower,
    upper = upper,
    control = list(
      s = 30,
      maxit = 60,
      trace = 0
    )
  )

  setNames(as.numeric(fit$par), names(empty_result))
}

Define the statistics that we will use.

validation_stats <- function(observed, predicted) {
  keep <- complete.cases(observed, predicted)
  observed <- observed[keep]
  predicted <- predicted[keep]

  rmse <- sqrt(mean((observed - predicted)^2))
  mae <- mean(abs(observed - predicted))
  bias <- mean(predicted - observed)

  if (length(observed) > 2 &&
      sd(observed) > 0 &&
      sd(predicted) > 0) {
    r2 <- cor(observed, predicted)^2
  } else {
    r2 <- NA_real_
  }

  data.frame(
    RMSE = rmse,
    MAE = mae,
    Bias = bias,
    R2 = r2
  )
}
  • RMSE gives more weight to large errors.
  • MAE is the average absolute error.
  • Bias is predicted minus observed EF.
  • \(R^2\) describes association, but it does not measure agreement by itself.

11.4 Move from one split to k-fold cross-validation

One split depends on which events happened to enter the test group. In k-fold cross-validation, we divide the events into \(k\) folds, fit on \(k-1\) folds, and validate on the remaining fold. Every fold takes a turn as validation data.

11.4.1 Create event-level folds

make_folds <- function(data, k = 5, seed = 100) {
  set.seed(seed)

  events <- sample(unique(data$drydown_id))

  fold_table <- data.frame(
    drydown_id = events,
    fold = rep(seq_len(k), length.out = length(events))
  )

  merge(
    data,
    fold_table,
    by = "drydown_id",
    all.x = TRUE,
    sort = FALSE
  )
}

Inspect one assignment.

11.4.2 Repeat the k-fold process

Repeated cross-validation reshuffles the fold assignment and runs the complete k-fold process again. With 5 folds and 10 repeats, each method can produce as many as 50 fitted models. Those fitted models form an ensemble.

11.5 Cross-validate NLS2/NLS and PSO

The shared function below calls either fit_NLS() or fit_PSO(). It stores the fitted parameters, validation statistics, and withheld predictions.

cross_validate_piecewise <- function(
    data,
    fit_function,
    method,
    k = 5,
    repeats = 10,
    seed = 100) {

  parameters <- data.frame()
  statistics <- data.frame()
  predictions <- data.frame()

  for (repeat_id in seq_len(repeats)) {
    cv_data <- make_folds(
      data,
      k = k,
      seed = seed + repeat_id
    )

    for (fold_id in seq_len(k)) {
      train <- subset(cv_data, fold != fold_id)
      test <- subset(cv_data, fold == fold_id)

      set.seed(seed + 1000 * repeat_id + fold_id)

      pars <- tryCatch(
        fit_function(train$SM, train$EF),
        error = function(e) c(
          theta_d = NA_real_,
          theta_w = NA_real_,
          EF_max = NA_real_
        )
      )

      if (length(pars) != 3 || any(!is.finite(pars))) {
        next
      }

      predicted <- piecewise_EF(
        test$SM,
        pars["theta_d"],
        pars["theta_w"],
        pars["EF_max"]
      )

      parameters <- rbind(
        parameters,
        data.frame(
          repeat_id = repeat_id,
          fold_id = fold_id,
          method = method,
          theta_d = unname(pars["theta_d"]),
          theta_w = unname(pars["theta_w"]),
          EF_max = unname(pars["EF_max"])
        )
      )

      fold_stats <- validation_stats(test$EF, predicted)
      fold_stats$repeat_id <- repeat_id
      fold_stats$fold_id <- fold_id
      fold_stats$method <- method
      statistics <- rbind(statistics, fold_stats)

      predictions <- rbind(
        predictions,
        data.frame(
          repeat_id = repeat_id,
          fold_id = fold_id,
          method = method,
          observation_id = test$observation_id,
          SM = test$SM,
          EF_observed = test$EF,
          EF_predicted = predicted
        )
      )
    }
  }

  list(
    parameters = parameters,
    statistics = statistics,
    predictions = predictions
  )
}
Do not let tryCatch hide model problems

tryCatch() is appropriate when many folds are fitted, but it can hide why a fit failed. While developing the function, run a selected training fold without tryCatch() so that R shows the full error.

11.6 Cross-validate Random Forest

Random Forest does not return the three physical parameters. We will store its validation statistics, withheld predictions, and fitted forest models.

rf_statistics <- data.frame()
rf_predictions <- data.frame()
rf_models <- list()

for (repeat_id in seq_len(n_repeats)) {
  cv_data <- make_folds(
    drydown_data,
    k = k_folds,
    seed = analysis_seed + repeat_id
  )

  for (fold_id in seq_len(k_folds)) {
    train <- subset(cv_data, fold != fold_id)
    test <- subset(cv_data, fold == fold_id)

    fit <- tryCatch(
      {
        set.seed(analysis_seed + 1000 * repeat_id + fold_id)
        randomForest(
          EF ~ SM,
          data = train,
          ntree = 500,
          mtry = 1,
          nodesize = 10
        )
      },
      error = function(e) NULL
    )

    if (is.null(fit)) {
      next
    }

    predicted <- predict(fit, newdata = test)

    fold_stats <- validation_stats(test$EF, predicted)
    fold_stats$repeat_id <- repeat_id
    fold_stats$fold_id <- fold_id
    fold_stats$method <- "Random Forest"
    rf_statistics <- rbind(rf_statistics, fold_stats)

    rf_predictions <- rbind(
      rf_predictions,
      data.frame(
        repeat_id = repeat_id,
        fold_id = fold_id,
        method = "Random Forest",
        observation_id = test$observation_id,
        SM = test$SM,
        EF_observed = test$EF,
        EF_predicted = as.numeric(predicted)
      )
    )

    rf_models[[length(rf_models) + 1]] <- fit
  }
}

parameter_range <- function(x) {
  c(
    median = median(x, na.rm = TRUE),
    lower = quantile(x, 0.025, na.rm = TRUE, names = FALSE),
    upper = quantile(x, 0.975, na.rm = TRUE, names = FALSE)
  )
}

Summarize any ensemble matrix with one small function.

summarize_curves <- function(prediction_matrix) {
  data.frame(
    SM = sm_grid,
    EF_median = apply(prediction_matrix, 1, median, na.rm = TRUE),
    EF_lower = apply(
      prediction_matrix,
      1,
      quantile,
      probs = 0.025,
      na.rm = TRUE
    ),
    EF_upper = apply(
      prediction_matrix,
      1,
      quantile,
      probs = 0.975,
      na.rm = TRUE
    )
  )
}

nls_curve_summary <- summarize_curves(nls_curve_matrix)
pso_curve_summary <- summarize_curves(pso_curve_matrix)
rf_curve_summary <- summarize_curves(rf_curve_matrix)

What the spatial range means

The range answers: How much does the fitted parameter change when the cell is fitted with different 80% subsets of its matched observations? It does not claim that every source of uncertainty has been measured.

11.11.3 Write a cell function for uncertainty

First define a small summary function.

spatial_summary <- function(x) {
  lower <- quantile(x, 0.025, na.rm = TRUE, names = FALSE)
  upper <- quantile(x, 0.975, na.rm = TRUE, names = FALSE)

  c(
    median = median(x, na.rm = TRUE),
    lower = lower,
    upper = upper,
    width = upper - lower
  )
}

Now create the function passed to terra::app(). It returns four values for each of the three parameters: median, lower bound, upper bound, and range width.

n_time <- nlyr(SM)
spatial_data <- c(SM, EF)

fit_PSO_uncertainty <- function(x) {
  SM_cell <- x[1:n_time]
  EF_cell <- x[(n_time + 1):(2 * n_time)]

  keep <- is.finite(SM_cell) & is.finite(EF_cell)
  SM_cell <- SM_cell[keep]
  EF_cell <- EF_cell[keep]

  empty_result <- rep(NA_real_, 12)

  if (length(SM_cell) < 20 || length(unique(SM_cell)) < 4) {
    return(empty_result)
  }

  fitted_parameters <- matrix(
    NA_real_,
    nrow = n_spatial_samples,
    ncol = 3
  )

  set.seed(analysis_seed)

  for (i in seq_len(n_spatial_samples)) {
    sample_id <- sample(
      seq_along(SM_cell),
      size = floor(sample_fraction * length(SM_cell)),
      replace = FALSE
    )

    fitted_parameters[i, ] <- tryCatch(
      fit_PSO(SM_cell[sample_id], EF_cell[sample_id]),
      error = function(e) c(
        theta_d = NA_real_,
        theta_w = NA_real_,
        EF_max = NA_real_
      )
    )
  }

  fitted_parameters <- fitted_parameters[
    complete.cases(fitted_parameters),
    ,
    drop = FALSE
  ]

  if (nrow(fitted_parameters) < 5) {
    return(empty_result)
  }

  c(
    spatial_summary(fitted_parameters[, 1]),
    spatial_summary(fitted_parameters[, 2]),
    spatial_summary(fitted_parameters[, 3])
  )
}
Keep tryCatch, but test first

The full raster calculation needs tryCatch() so that a few failed resamples do not stop every cell. Before running the map, use the one-cell code above without the outer spatial wrapper and inspect any errors.

11.12 What should we conclude?

  1. A single train/test split introduces the idea of out-of-sample prediction.
  2. K-fold cross-validation rotates the validation group so every event is tested.
  3. Repeated cross-validation creates an ensemble of parameter sets, predictions, and validation statistics.
  4. Parameter ranges describe sensitivity of the fitted physical thresholds to resampling.
  5. Prediction ribbons show variation among fitted ensemble members.
  6. Spatial uncertainty maps distinguish locations with stable estimates from locations whose fitted parameters change strongly across resamples.
  7. These ensemble ranges are useful diagnostic summaries, not complete confidence intervals.

11.13 Let’s discuss

  1. Why should complete drydown events remain together in one fold?
  2. How can a model have small training error but large validation error?
  3. What does a wide parameter range tell us about the data at a site or raster cell?
  4. Why is a narrow range suspicious when many parameter estimates reach an optimization bound?
  5. Why can Random Forest have prediction uncertainty but not uncertainty in \(\theta_d\) or \(\theta_w\)?
  6. What additional sources of uncertainty are not represented by these resampling ranges?
